A program that writes one short text to `/output/entry.txt`: a ferryman who has crossed the same river ten thousand times, who neither hurries the water nor fights it — read the water, dip the oar, go. The courage is shown, not instructed, and the last line is the thought that stays: the far bank is no closer for worrying, and no farther for calm. `main.py` (Python 3.13, stdlib only, no network) checks the text against the gate's caps (1–280 Unicode code points, not only white space) and writes it out deterministically.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
